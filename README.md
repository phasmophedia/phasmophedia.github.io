# PHASMOPHEDIA — versión 2

## Abrir
Abre `index.html` directamente en un navegador. Esta versión integra los datos dentro del propio HTML y no necesita cargar `ghosts.json` ni ejecutar un servidor.

## Qué incluye
- Diseño de diario abierto con páginas de papel envejecido y encuadernación central.
- Selector de evidencias funcional.
- Filtro de fantasmas compatibles.
- Índice de fantasmas con buscador.
- Expedientes detallados con evidencias, velocidad, cacerías, habilidad, debilidad, comportamiento e identificación.
- Adaptación a móvil.

## Aviso
Proyecto de fans no oficial y no afiliado a Kinetic Games. Los nombres y elementos de Phasmophobia pertenecen a sus titulares. Las mecánicas deben contrastarse con la versión actual del juego.
